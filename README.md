# v-awesome-directives

🧩 A collection of useful Vue 3 directives — modular, lightweight, and easy to integrate.

## ✨ Features

- 📦 Tree-shakable: Import only the directives you need
- 💡 Simple to use in any Vue 3 app
- 🧰 Useful directives like:
  - `v-click-outside`
  - `v-focus`
  - `v-debounce`
  - `v-tooltip` (customizable)

## 📦 Installation

```bash
npm install v-awesome-directives
# or
yarn add v-awesome-directives
